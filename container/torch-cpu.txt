# CPU-only PyTorch for the container image, installed by the Containerfile with
# `uv pip install --require-hashes --no-deps --index-url https://download.pytorch.org/whl/cpu`.
#
# Versions must equal the torch, torchaudio and torchvision versions in uv.lock;
# the image build fails otherwise.
# Each package lists the sha256 of the manylinux_2_28 wheel that runs on cp314
# (a cp314 or py3-none wheel) for x86_64 and aarch64, copied from the #sha256=
# fragments on the download.pytorch.org/whl/cpu index pages. When uv.lock moves
# any of these versions, update this file too:
# `uv run --frozen --no-sync python scripts/update_torch_pins.py` rewrites it.
# The CUDA image (TORCH_VARIANT=cuda) has no file of its own: it installs the
# PyPI builds uv.lock pins and hashes, so updating uv.lock covers it.
