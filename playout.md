AutoDJ is the basis for this station. AutoDJ has folder management, editable song points, the agreed transitions, Smooth and Stereo Tool processing, and a rolling clockwheel. The server makes one continuous mix; the browser controls and monitors it. Use stream mode for this setup.

On this machine, open [AutoDJ](http://127.0.0.1:8081). To start it again from this folder, run `.venv\Scripts\python.exe -m autodj serve --stream --no-server-audio`. In the browser, use Listen to hear the stream. Keep playing without listeners controls whether the station continues after you stop listening.

The original sound references are the B and C examples (`local/playout-round9/index.html`, local only). The original-file approach follows the later D/E listening tests: D used 6 dB of extra Stereo Tool AGC drive and E used 9 dB. The default is 7 dB. The everyday workflow is:

1. Open Library, then Library tools. Enter a Folder path on the computer running AutoDJ, choose Music, and select Add folder. This first version adds folders; individual music files can follow.
2. Add subfolders and Perform advanced analysis both start checked for music. Each folder remembers its choices. New songs become available after the short read that finds tags and basic points. They can play in Random walk or the queue while detailed analysis is pending.
3. Loudness measurement and advanced matching run in the background. Similarity needs matching data. Random walk, Least recently played and Clockwheel use the whole playable library. If a song has no loudness measurement yet, the playback worker measures it before loading it. Later plays reuse that small saved measurement; no separate audio file is created.
4. Choose Voice liner as the folder type to add IDs, voice tracks or jingles. Their short scan finds Start, End and a suggested Segue; they do not need the advanced music-matching job. For C:\station\drops\drops, leave Add subfolders unchecked. Add C:\station\drops\sweepers separately. The existing upload button still writes to its original liner folder.
5. Use Rescan after adding or moving files. Overlapping folder registrations do not duplicate a file. A confirmed move of an unchanged recording retains its points, history and analysis. Remove stops using that folder without deleting files or saved information. A file covered by another registered folder stays available.
6. Open Library → Browse library. Choose All music, All voice liners, or one registered folder. Leave the search text blank to browse that folder, or enter an artist, title or filename. Previous and Next move through pages of 100 tracks. Each row has Play now, Play next, Add to queue and Track info. Folder browsing follows that folder's Add subfolders choice. Search Library in the Queue tab remains available.
7. Choose Track info from Now Playing, a library/search result, a queued track, or Settings → Voice liners → Files. It opens the same Track info tab for songs and liners. Details include title, artist, album, year, genre, duration, folder, filename, last played, BPM/key and analysis status. Below those are the cue points and separate audio preview. Preview buttons play the selected cue. Use preview position copies the preview time into a cue without seeking the station. Saving points does not repeat analysis.
8. Start with Random walk to audition the library. Then choose Clockwheel to run the imported plague2024.pal rotation. Keep playing without listeners lets the station continue when the browser closes.

There is no required cue-review step. AutoDJ fills points it can find and labels their source in the editor. The first timed lyric can supply Intro; the last lyric and its estimated duration can help with Outro. Existing loudness detection supplies rough suggestions when lyric timing is unavailable. These suggestions take effect immediately, as agreed. They can be wrong about vocals, so adjust them when you hear a clash. Manual and imported points take priority over later analysis of the same file. If file contents change, AutoDJ clears the old cues and analysis before scanning again. This includes retagging under the current file-identity check; confirmed moves of unchanged files keep their cues.

Track info stays on the recording you chose when the station advances. You can switch tabs and return without losing edits or library filters. Choosing a different recording with unsaved cue edits opens “Save changes to [track]?” with Save and Discard. Save must succeed before switching; a failed save keeps the draft. Discard switches without saving. Escape cancels the switch. Liners use the same workflow, showing Start, Segue, End and Overlap start.

Analysis status says Complete when matching data exists, Pending when enabled but not yet available, or Not enabled for this folder. Pending does not mean that particular song is currently being analyzed. Liners do not need this advanced music analysis. Loudness analysis is shown separately. The approved restart loaded Track info on port 8081. Refresh the page to see it.

Songs keep five points:

- Start is the first audio to play, after unwanted leading silence.
- Intro is where the first words begin. An empty Intro allows no talk-over space at the opening.
- Outro is where a liner may begin over the ending. An empty Outro allows no early talk-over space.
- Segue is where the next item enters. If empty, use Outro, then End. A later Outro does not move a saved Segue.
- End is the last wanted audio, including any tail worth keeping.

IDs, jingles and voicetracks all remain liners. In Track info, Allow start over outro defaults off: the liner starts at the outgoing song's Segue. Turn it on for a voicetrack that may begin over the song's Outro.

Liners use Start, Segue, End and Overlap start. Segue marks the end of the main content; End keeps the remaining tail. Leave Overlap start blank to bring in music at the liner's Segue, or End if Segue is blank. Set it to 0 to fit the main content before the next song's vocals when timing allows. With no incoming Intro, music waits until the liner's Segue. The liner starts no later than the new song. A short liner does not pull the song ahead of the outgoing song's Segue; a long one can delay it. Internal pauses remain intact.

Segue suggestions follow a sustained final drop in loudness. They use a shorter measurement for liners so brief stingers get useful points. An interior pause followed by more speech does not count. Listen and adjust if a quiet final word gets covered. Existing liners without a Segue get a suggestion on the next scan, within their saved Start and End. Manual or imported points, including an intentionally cleared Segue, are preserved.

A positive Overlap start is the number of seconds after the liner's saved Start at which the next song may enter. It cannot be later than the liner's Segue. The remaining liner audio plays over the song without being faded or cut. Plague 25 uses 5.3 seconds, keeping its reverb through End at about 8.809. The two imaging IDs and Stingers 2 through 5 keep Overlap start at 0. The sweeper now uses 9.35 seconds, its Segue, instead of 10.77. All 12 current IDs have Allow start over outro off.

The station settings are:

- Pick mode: Random walk for the first listening test, then Clockwheel. Least recently played is also available on its own. Similarity retains its matching-based behavior.
- Tracks before a song can repeat and Tracks before an artist can repeat: keep the existing controls. Random walk, least-recent selection and clock slots marked EnforceRules use them. PAL slots marked NoRules retain that choice.
- Transition mode: Use saved segue points. Selecting Clockwheel also selects this mode. The older modes remain available.
- Crossfade seconds: 1.5. The exponential fade starts 0.5 seconds before Segue; the new item enters at Segue at its balanced level, with up to 1 second of the old song underneath. Changing this setting scales the timing. A short file tail limits overlap.
- Fade-in seconds: retained for older modes and hidden for saved-point playback.
- Transition effect: none. EQ-ducked crossfade stays off. Beatmatch, Drop mixing, Key shift, Phrase align, Outro / intro align, Filter sweep and Keep vocals apart do not override saved-point playback. Controls are hidden when they do not apply; their values remain available for older modes.
- Voice liners: retain the existing enable switch, Every N tracks, Every N minutes, random-window triggers and Random/Sequential rotation. These choose automatic liners outside Clockwheel. Clockwheel takes its liners from the clock slots.
- Talk up to the vocal: on. Saved-point playback fits the liner's main content before the incoming vocal, using the outgoing Outro only when Allow start over outro is checked, and delaying incoming music when needed. The remaining tail can continue underneath.
- Duck depth: use the existing setting at 0 dB. There is no extra duck control for this setup.
- Output processing: Stereo Tool for the next listening pass. Smooth, Off and ReplayGain remain available. Smooth and Stereo Tool balance original files using saved loudness measurements, without stacking ReplayGain or the separate intro-only lift. The choice is saved in playback profiles. A change takes effect when a newly rendered song reaches playback; the playing song and its handoff finish with their current setting.
- AGC drive boost: 7 dB by default, adjustable from 0 to 12 in Settings, Sound when Stereo Tool is selected. It controls how strongly the processor works on the whole mix, including quiet openings, middles and endings. It is not a per-song maximum gain. Zero uses the selected preset's original drive; it does not turn AGC off. Changing it reloads the processor and can briefly use fallback audio. The old Boost quiet sections setting is discarded.
- Low, mid and high EQ: saved across restarts. The station uses Low at +3 dB, with Mid and High at 0 dB.
- Keep playing without listeners: on for unattended operation. Leave it off for the existing listener-triggered stream behavior.
- Clockwheel: import the PAL text file under Library tools, give it a name, and choose resync minutes. 0 means near the top of each hour; 0, 30 adds the half-hour. An empty list disables resync.

The clock chooses each next item as playback advances. It preserves PAL folder order, Dir versus SubDir scope, smLRP versus random selection, and EnforceRules versus NoRules. smLRP means least recently played; ties among never-played songs are random. Near a resync time, the rotation restarts at the nearer natural song handoff. It does not force an exact-time cut through the playing song. A selection replaced before it is heard stays in the unplayed pool. Missing or exhausted slots appear in clock status.

Queue items can be added, removed and reordered during playback. Once a song starts, its next handoff is already prepared. The page identifies that next song so it is clear where queue changes take effect. Play now interrupts the prepared sequence. Skipping before the next song has begun starts it at its Start point, preserving its unheard intro.

Smooth and Stereo Tool decode the original ahead of playback into the existing memory buffer. Music receives a fixed overall gain to -28 LUFS. Liners keep their low-cut filter and 3:1 voice compressor, then are balanced to -25 LUFS, about 3 dB above music. That avoids blindly boosting an already loud jingle. Tracks and liners are mixed, then EQ is applied. Smooth uses its built-in compressor and limiter. Stereo Tool uses the selected preset with the AGC drive boost, followed by the existing 5.8 dB output lift and peak limiter. The processor stays running across songs and liners. Neither path uses the old separate quiet-section leveler or writes audio copies. The catalog stores measurements and file identity so changed recordings are measured again.

The earlier examples used individual levels for the produced IDs and Plague. The common liner preset will not reproduce those levels exactly. Listen to raw voice and produced imaging before changing that shared preset. Output gain stays fixed during a programme; per-excerpt loudness matching from the audition files is not part of live playback. An offline check of three saved mixes reproduced the B master output exactly with today's Smooth filters. Flat EQ means 100%, labelled Unity, or 0 dB; the EQ repair preserves that sound.

Stereo Tool adds automatic gain control, a five-band compressor and a final limiter. Its preset is included with AutoDJ. Download the command-line program from [Thimeo](https://www.thimeo.com/stereo-tool/download/) and put it in `./tools/stereo-tool/`. The default executable is `stereo_tool_cmd.exe` on Windows and `stereo_tool_cmd` elsewhere, relative to the directory where you start AutoDJ. To use another location or a command on PATH, set `stereotool_path` under `[playback]` in config.toml. This machine uses `C:/git/AutoDJ/tools/stereo-tool/stereo_tool_cmd.exe`. The executable is installed separately and is not included in AutoDJ. The browser's Output processing choice selects it; there are no extra compressor controls to configure.

Thimeo says its [trial has no time limit](https://www.thimeo.com/help/stereo-tool/). Unlicensed paid features can add beeps or spoken messages; its [free features do not add audio reminders](https://www.thimeo.com/stereo-tool/licenses/). Our exact saved preset processed a seven-minute test file without stopping or reporting unsupported paid features. If the external processor fails, AutoDJ keeps audio moving through a limited fallback, reports the fault in playout status, and tries to recover. That fallback keeps the station audible but sounds less controlled than the normal processing.

config.toml still supplies installation defaults. The active library saves its folder lists, checkbox choices, points and clock in library.db. Configured folders are imported once; an intentionally empty list stays empty. Browser playback settings remain in web_state.json. Loudness measurements are saved in library.db; no processed audio copies are written. Playback profiles do not change source folders. Existing Beets/index tools remain available as advanced jobs.

Keep every play in the library database, with no automatic age or count limit. History shows the latest 500; older plays stay saved for future date browsing. Each song also keeps its own last-played time, which least-recently-played selection already uses. That time does not expire when a song leaves the visible history, whether it was played yesterday, weeks ago or months ago. A confirmed file move keeps the same library record and last-played time.

The history update saves new plays through the existing background writer, so the audio thread does not write to disk. It restores the recent view on startup and needs no new setting. The approved restart loaded this update and imported the 26 entries still visible from the previous session. Date browsing can come later.

A restart keeps the clock's saved position but chooses a song for that slot again; it does not restore the prepared next song or resume the interrupted audio. Ties for least recently played are random. That explains Blackstreet changing to Cardigans after the restart: both were unplayed candidates in the same 90a slot. A song that was only prepared stays in the unplayed pool.
